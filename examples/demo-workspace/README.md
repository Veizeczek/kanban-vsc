# Kanban demo workspace

Open **this folder** (`examples/demo-workspace`) as a separate VS Code workspace, then run **Kanban: Open Kanban Board**. The extension reads the first workspace folder; opening the repository root will show its own `docs/` instead.

Use a copy of this folder for a disposable demo. Dragging cards, changing goals, pinning and deleting documents modify the demo files. Refresh only reads them. Do not click **Save** unless you intend to commit the demo changes in the surrounding Git repository.

## Suggested walkthrough

1. Open the board: all four status columns contain sample tasks.
2. Find the pinned **Column search** card in Active.
3. Click the search icon in Active; type `search`, then a phrase with no matches. Press Escape.
4. Move **Quick capture** from Proposals to Active and open its Markdown preview.
5. Visit Goals, Architecture and Other to see each supported document type.
6. Click Refresh and check that filenames and document contents stay unchanged.

All content is fictional. Dates and checkboxes demonstrate the UI; they are not release certification.
